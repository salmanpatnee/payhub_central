# Front end (resources/js)

## Overview

The Vue 3 and Inertia front end. It follows the Laravel Vue starter kit layout, with PayHub's look laid on top (spec 0003). The app is light only.

## Key files

| File | Owns |
|---|---|
| `../css/app.css` | All design tokens (colours, radius, status colours, focus ring). The only place colour values are written |
| `lib/formatMoney.ts` | The only place cents become display text. Whole cents in, 2 decimals, grouping, no symbol, `—` for a bad value |
| `lib/formatPercent.ts` | The only place a share becomes "74%" (one decimal under 10%, "–" for no links) |
| `lib/cardWarnings.ts` | The warning limits for a deployment card (3 links, 5% failed, 25% expired) and the one function that applies them |
| `lib/formatRelative.ts` | The only place times become "5 min ago" and the exact time text |
| `lib/deploymentStatus.ts` | The badge map and status notes, shared by the Home card and the Deployment page so they never disagree (spec 0009) |
| `lib/formatWindowRange.ts` | The only place a window's `from` and `to` become "1 Oct to 31 Oct" (spec 0009) |
| `pages/deployments/Show.vue` | The Deployment page, Focus view: period switch, three summary cards, link outcomes, an all periods table, then a collapsible Recent pulls table (closed by default, from the lazy `pulls` prop, spec 0010). The breadcrumb is set with `setLayoutProps` so a rename shows after a poll (spec 0009) |
| `pages/deployments/Index.vue`, `Create.vue`, `Edit.vue`, `components/RemoveDeploymentDialog.vue` | The Deployments list (status plus Edit, Pause or Resume, Remove per row), the add form, the edit form and the remove dialog (specs 0011, 0012) |
| `lib/flashToast.ts` | Turns the server's `Inertia::flash('toast', ...)` into a `vue-sonner` toast. The place to change toast behaviour |
| `pages/staff/Index.vue`, `Create.vue`, `Edit.vue`, `components/RemoveStaffDialog.vue` | Staff logins (spec 0013). Your own row shows a "You" badge and no actions. Edit has two forms (details, and set new password) and sets its breadcrumb with `setLayoutProps` |
| `composables/useNow.ts` | One shared clock (30 second tick) for every relative time |
| `components/MoneyByCurrency.vue` | One row per currency. Never adds across currencies |
| `components/DeploymentCard.vue` | The Dashboard card (Sunrise look). The whole card is one link to the deployment page (stretched title link), with an arrow button. Gets one period from the page, so switching makes no request |
| `components/PageHeader.vue`, `EmptyState.vue`, `StatCard.vue`, `RelativeTime.vue`, `SchedulerBanner.vue` | The shared parts every page uses |
| `layouts/app/AppSidebarLayout.vue` | The shell: skip link, sidebar, top bar, scheduler banner, `<main id="main-content">` |

```bash
npm run check        # lint and format (vp check)

npm test             # vp test, front end unit tests
npm run build        # also regenerates the Wayfinder routes
```

## Conventions

- Use tokens only. No hard coded colours in components. Green, amber and red mean status and nothing else, and always come with a word or icon. Orange `--brand` is for the logo mark, small shapes and hover edges (like the card arrow button), never text. Blue (`--info`) is for neutral counts such as Links, never for status.
- Light only. Nothing sets a `dark` class. Do not add `dark:` styling or a theme switch.
- Format money and time with the helpers above, never inline. Never add amounts across currencies.
- Every page has exactly one `h1`, through `PageHeader`. Exceptions: auth pages (the auth layout's title) and settings pages (an `sr-only` h1). Pages use `p-4 md:p-6` padding and `max-w-7xl`.
- Icons come from `@lucide/vue` (not `lucide-vue-next`).
- Money in the browser is whole cents. No float maths.
- The shell (`AppShell`) gives every page the blue and peach `page-glow` background, and the sidebar is the `floating` variant, so page content sits directly on the glow. Cards and tiles are the white objects.
- The Dashboard page also shows a summary row: paid money per currency (never added across currencies) and a payments count, worked out in `pages/Dashboard.vue` from the cards for the chosen period.
- The Home page period switch lives in `pages/Dashboard.vue` state, not the URL, and `usePoll` reloads only `deployments` so the choice survives a poll. The Deployment page keeps its own four option period switch in `Show.vue` state, and its `usePoll` reloads only `deployment`.

## Gotchas

- `components/ui/*` is the shadcn-vue kit. It is excluded from lint and format. Edit it only to match the design tokens, and expect merge care when updating it.
- `routes/`, `actions/` and `wayfinder/` are generated by Wayfinder and are gitignored. Run `npm run build` to refresh them after changing Laravel routes.
- `vue-tsc` loses the `v-slot` scope after a literal `//` inside a template attribute (for example `placeholder="https://x.com"`), which gives false "Cannot find name" errors. Put such text in a script constant and bind it.
- The Inertia `Form` keeps page state after a PATCH or PUT, so `setLayoutProps` breadcrumbs from the old page stay (a stale name). Pass `:options="{ preserveState: 'errors' }"` to the form; `Form` has no `preserve-state` prop, and an unknown attribute falls through to the HTML `<form>`.
- `lib/formatRelative.ts` also holds `formatDate` (the "Date added" text). Use it, not an inline `Intl.DateTimeFormat`.
- The kit's own focus rings are full strength orange. Do not weaken them back to `ring-ring/50`.
